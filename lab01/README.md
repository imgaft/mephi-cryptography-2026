# Лабораторная работа № 1

## Тема
Шифрование данных методами подстановки, перестановки
и полиалфавитными шифрами.

## Цель
Приобретение навыков программной реализации
простейших методов симметричного шифрования
и дешифрования.

## Вариант
Порядковый номер в группе: 30.

30 mod 12 = 6.

Вариант № 6.

## Задание
Реализовать многоалфавитное шифрование
русского текста с использованием подстановочных
алфавитов № 1 и № 3 из таблицы 2.

Программа должна:
1. Принимать исходный текст.
2. Выполнять шифрование.
3. Выводить криптограмму.
4. Выполнять дешифрование.
5. Проверять восстановление исходного текста.

## Структура
- src/main.py — реализация алгоритма.
- tests/test_main.py — автоматические тесты.
- report/ — отчёт в формате PDF.
