# Лабораторная работа №2

## Тема
Изучение алгоритма RSA.

## Цель
Освоить механизм шифрования и дешифрования данных
в криптографической системе с открытыми ключами RSA.

## Вариант
Номер в списке группы: 30.

Количество вариантов: 14.

30 mod 14 = 2.

Вариант №2.

## Исходные данные

- p = 211
- q = 317

## Расчётные параметры

- n = 66887
- φ(n) = 66360
- e = 11
- d = 24131

Открытый ключ: (11, 66887).

Закрытый ключ: (24131, 66887).

## Возможности программы

1. Проверка простоты чисел.
2. Проверка взаимной простоты.
3. Генерация ключей RSA.
4. Выбор минимального допустимого e.
5. Вычисление закрытого показателя d.
6. Шифрование UTF-8 текста.
7. Дешифрование сообщения.
8. Проверка корректности восстановления текста.
