# Лабораторная работа №3 — Электронная подпись, вариант №7

Учебная реализация схемы подписи ГОСТ Р 34.10-94 с контрольной суммой из задания.

## Параметры

- `p`: 512 бит, простое.
- `q`: 256 бит, простое; `q | (p - 1)`.
- `a`: `1 < a < p - 1`, `a^q mod p = 1`.
- Фиксированные параметры находятся в `get_report_parameters()`.
- Проверка простоты выполняется тестом Миллера–Рабина (40 раундов); при подготовке параметры дополнительно проверены SymPy.
- Малые параметры `get_demo_parameters()` оставлены **только для воспроизводимых арифметических тестов**.

## Вариант №7

UTF-8 → 16-битные блоки (big-endian), последний нечётный байт дополняется нулём справа; для каждого блока `checksum = ROL16(checksum XOR block, 1)`.

## Запуск

Из корня проекта:

```bash
python3 -m src.main
python3 -m unittest discover -s tests -v
```

Результаты запусков — в `report/`.

## Ограничения

16-битная контрольная сумма **не криптографическая хеш-функция**. Существуют коллизии, поэтому даже с параметрами установленной длины подпись не обеспечивает криптографическую защиту документа и не является полной реализацией стандарта ГОСТ Р 34.10-94 (в частности, не применяется ГОСТ Р 34.11). В демонстрации проверяются конкретные изменения, а не гарантируется обнаружение любых модификаций.
