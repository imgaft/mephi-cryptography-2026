Изучение криптографических протоколов распределения ключей
на эллиптических кривых и программная реализация протокола
Диффи–Хеллмана (ECDH).

## Исходные данные

Вариант определяется по формуле:

V = (30 mod 15) + 1 = 1

Параметры варианта № 1:

| Параметр | Значение |
|---|---|
| a | -1 |
| b | 1 |
| p | 29 |
| G (методичка) | (9, 27) |
| k1 | 4 |
| k2 | 17 |

Эллиптическая кривая:

y² = x³ - x + 1 (mod 29)

## Особенность исходных данных

При проверке обнаружено, что базовая точка G = (9, 27),
указанная в методических материалах, не принадлежит
заданной эллиптической кривой.

Проверка:

- Левая часть: 27² mod 29 = 4
- Правая часть: (9³ - 9 + 1) mod 29 = 25

Поскольку 4 != 25, исходная точка некорректна.

Для выполнения протокола сохранена координата x = 9.

Программным перебором найдены допустимые точки:

- (9, 5)
- (9, 24)

Выбрана точка G = (9, 24), поскольку она требует
минимального изменения исходной координаты y.

Проверка:

24² mod 29 = 25

Порядок выбранной точки: 37.

Остальные параметры варианта сохранены без изменений.

## Реализация

Программа выполняет:

1. Проверку простоты модуля.
2. Проверку невырожденности эллиптической кривой.
3. Проверку принадлежности точек кривой.
4. Вычисление обратного элемента по модулю.
5. Сложение и удвоение точек.
6. Умножение точки на скаляр методом double-and-add.
7. Генерацию открытых ключей пользователей.
8. Независимое вычисление общего секрета.
9. Проверку совпадения результатов.
